# 🎬 Movie Theatre Booking System

A beginner-friendly **Python command-line movie booking system** that allows users to browse available movies, book tickets, calculate the total cost, and receive a booking receipt.

## ✨ Features

* 🎥 Displays a list of available movies and their prices
* 🎟️ Books tickets for selected movies
* 💰 Calculates the cost of each booking
* 🧾 Generates a final receipt
* ➕ Allows customers to book multiple movies
* ❌ Handles unavailable movie selections
* 🔄 Uses functions to organise the programme

## 🛠️ Technologies Used

* **Python 3**
* Python dictionaries
* Functions
* `for` loops
* `while` loops
* `if / elif / else`
* User input
* Lists
* Basic arithmetic

## 🚀 How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/movie-theatre-booking.git
```

3. Open the project folder:

```bash
cd movie-theatre-booking
```

4. Run the program:

```bash
python main.py
```
